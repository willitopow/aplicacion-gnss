# libs

Aquí va la librería opcional para leer Excel sin conexión.

Descárgala con:

```bash
curl -L -o libs/xlsx.full.min.js https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js
```

Es SheetJS (licencia Apache-2.0). Si este archivo no está, la aplicación intenta cargarla desde internet solo cuando abres un `.xls` o `.xlsx`.
