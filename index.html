2. Capas

Cada código forma una capa. Elige cómo dibujarla: puntos, línea abierta (cerca, vía), polígono cerrado (lindero, casa) o círculo (fuente, con 3 o más puntos). Los puntos se unen según la columna Orden de unión, que sigue el croquis. Escribe los números de los puntos: 1-2-3-4-1 cierra una casa; usa ; para separar figuras distintas dentro de la misma capa (1-2-3; 5-6-7). Si la celda está vacía, se unen en el orden de sus nombres.

Croquis: unir puntos por número

Una línea por figura: NOMBRE | tipo | orden. Tipo: poligono, circulo, linea o puntos. Los números pueden venir de cualquier código. Las líneas que empiezan con # se ignoran.

4. Curvas de nivel y alturas

Usa la altura (h) de cada punto. Puedes cambiar una altura, borrar un punto o restaurarlos; las curvas se recalculan solas. Las curvas solo llegan hasta el área que cubren los puntos.

5. Exportar

DWG: es un formato propietario de Autodesk y no se genera de forma fiable desde el navegador. Exporta DXF (lo abren AutoCAD, BricsCAD, LibreCAD, QGIS y Civil 3D) y, si necesitas DWG, usa el script tools/dxf_a_dwg.sh con ODA File Converter (gratuito).
